# QUERY関数シミュレータ

日本語をうめるだけでGoogleスプレッドシートのQUERY関数の数式と実行結果がわかるインタラクティブ教材

🔗 **公開URL**: https://query.meetupsensei.com/

## 概要

「どの列を」「どんな行だけ」「まとめて集計」「どの順に」「何件まで」を日本語のフォームでうめていくと、対応するQUERY関数の数式が組み上がり、その実行結果のプレビューまで同じ画面に表示されます。日本語の入力欄と数式の各パーツは色で対応づけられているので、select / where / group by / order by / limit がそれぞれ数式のどこになるのかを見比べながら理解できます。サンプルの表（A1:E11）は架空のデータです。日本語／英語の切り替えとダークモードにも対応しています。

## 使い方

- 「どの列を」で表示したい列を選ぶ（select）
- 「どんな行だけ」で列・条件・値を指定して絞り込む。「条件をもう1つ足す」でかつ／または の複合条件にできる（where）
- 「集計する」にチェックを入れ、グループにする列と集計関数（平均・合計・件数・最大・最小）を選ぶ（group by）
- 「どの順に」で並べ替えの列と昇順／降順を選ぶ（order by）
- 「何件まで」で表示件数を絞る（limit）
- できあがった数式は「数式をコピー」でコピーしてスプレッドシートに貼り付けられる。「はじめに戻す」で初期状態に戻る
- 右上のボタンで言語（日本語／English）とダークモードを切り替える
